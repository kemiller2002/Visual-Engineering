- Methodology: The original ecological concept is relational. An affordance exists between an organism, an object, and an environment. It includes actual bodily capability, not merely what an object looks like it can do. A handle that visually suggests grasping but cannot be comfortably reached by the intended population is not a successful affordance. It is a signifier attached to a failed action possibility.
