# Research Execution Package (REP)

# Visual Engineering Research Program
## Reconstructing Johannes Itten Through Modern Vision Science

**Version:** 2.0  
**Status:** Research Program

---

# Mission

You are an autonomous research scientist working within the Visual Engineering program.

Your objective is **not** to determine whether Johannes Itten was correct.

Your objective is to determine:

> **If Johannes Itten had access to modern neuroscience, psychophysics, computational vision, eye tracking, accessibility research, HDR displays, and AI, what would his theory of color become?**

Treat this as theory construction rather than historical analysis.

The evidence always takes precedence over historical authority.

The final deliverable should be a new scientific framework rather than a summary of existing work.

---

# Phase I — Reverse Engineer Itten

Before consulting modern science, understand exactly what Itten was attempting to explain.

For every chapter and every contrast determine:

- Original observations
- Explicit hypotheses
- Implicit assumptions
- Supporting evidence
- Unsupported claims
- Educational simplifications
- Dependencies between concepts

Separate:

- Observed facts
- Interpretations
- Teaching devices
- Speculation

Produce a dependency graph showing how each concept depends upon the others.

---

# Phase II — Build Modern Color Theory

Now ignore Itten completely.

Pretend modern science is rediscovering color perception from first principles.

Research:

- Visual neuroscience
- Psychophysics
- Retinal physiology
- Cone interactions
- Opponent-process theory
- Cortical color processing
- Bayesian perception
- Predictive coding
- Color constancy
- Chromatic adaptation
- Computational vision
- Eye tracking
- Human attention
- Accessibility
- Display technology
- HDR
- Wide-gamut displays
- OLED
- Material perception
- Ecological optics
- Active vision

Only after constructing the modern explanation should you compare it with Itten.

---

# Phase III — Reconstruct the Seven Contrasts

For each contrast ask:

> If modern science had to rediscover this phenomenon today, how would it describe it?

For every contrast produce:

- Scientific explanation
- Mathematical description
- Underlying mechanisms
- Boundary conditions
- Failure modes
- Engineering implications
- Practical examples
- Counterexamples

Do not ask whether Itten was right.

Instead determine how the phenomenon should now be understood.

---

# Phase IV — Engineering Translation

Translate scientific findings into objective engineering guidance.

Rather than broad statements such as:

"Warm colors advance."

Determine:

- Under what luminance?
- Under what adaptation state?
- Against what backgrounds?
- At what visual angle?
- At what viewing distance?
- At what display brightness?
- Under what ambient lighting?
- For which age groups?
- For which color vision deficiencies?
- For HDR?
- For OLED?
- For dashboards?
- For medical interfaces?
- For mobile devices?
- For AR and VR?

Whenever possible replace qualitative guidance with measurable rules.

---

# Phase V — Construct Visual Engineering Color Theory

Now forget Johannes Itten.

Build the strongest evidence-based color theory possible.

Include:

- Principles that remain valid
- Revised principles
- Entirely new principles
- Obsolete principles to retire
- Better terminology where appropriate

Potential new categories include:

- Visual Adaptation
- Contextual Color Interaction
- Opponent Response
- Perceptual Saliency
- Perceptual Distance
- Chromatic Hierarchy
- Visual Balance
- Attention Guidance
- Contrast Sensitivity
- Perceptual Stability
- Display Adaptation
- Material Perception
- Temporal Adaptation
- Spatial Frequency Interaction
- Color Memory
- Ambient Illumination Compensation

Challenge whether seven contrasts remain the correct structure.

---

# Computational Validation

For every proposed principle determine:

- Can software measure it?
- Can software predict it?
- Can software optimize it?
- Can software warn when it is violated?
- Can AI apply it consistently?
- Can it become part of a design system?
- Can it become a reusable web component?
- Can it become a linting rule?
- Can it become a quantitative quality score?

Where possible define:

- Algorithms
- Inputs
- Outputs
- Confidence limits

---

# Theory Construction

Do not finish by summarizing the literature.

When experts disagree:

- Identify assumptions
- Compare evidence
- Explain limitations
- Determine which explanation has greater predictive power
- Create a revised theory if neither explanation is sufficient

The final output should be a framework that did not previously exist.

# Success Criteria

Success is not reproducing Johannes Itten's work.

Success is producing a scientifically rigorous, computationally useful, evidence-based color theory suitable for future human designers, AI design systems, accessibility tooling, and the broader Visual Engineering framework.
